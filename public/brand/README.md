# Brand assets

`openbridge-rgc.svg` is the production OpenBridge lockup. It keeps the product name primary and credits Alex Seidler in a scalable vector asset.

## Replacing the logo

1. Keep the filename `openbridge-rgc.svg` when revising the artwork so the React reference remains stable.
2. Preserve the exact product capitalization: `OpenBridge`.
3. Keep the Alex Seidler credit in the final lockup.
4. Optimize any raster replacement for the web and retain meaningful `alt` text.

The public folder is served at the site root by Vite, so the lockup is available at `/brand/openbridge-rgc.svg` during development and after a production build.
